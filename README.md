# Student-Management-System
Java console-based Student Management System with admin login, student CRUD operations, marks, percentage, grades, input validation, and file storage using core Java and OOP.
Student Management System (SMS)

A simple console application in Java to manage student records. This project was built as a graded java project to demonstrate object oriented programming, file handling, input validation and basic record management.

## About The Project The Student Management System assists an admin in managing students’ information through a menu-driven console interface. Admin can add students, view records, search by student ID, update details, delete records and save data permanently using file handling.

Details in each student record is basic personal details and academic details like name, age, course, marks, total marks, percentage and grade.
Features

- Admin login system.
- Add student records
- See All Student Records
- Lookup by Student ID.
- Update student information
- Remove student records
- Store marks of 3 subjects
- Automatic total marks calculation
- Automatic percentage calculation
- Generate grade by percentage
- Store student data in a file
- Load saved data on program start
- Input validation basics
